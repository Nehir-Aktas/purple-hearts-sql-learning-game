# 💜 Purple Hearts
A 34-level SQL learning game on a hospital database, from the simplest query to the hardest.

- Practice with doctors, nurses, patients, departments and diseases tables
- Turkish / English language option (the database content changes with the language too)
- Light / dark theme
- Queries run in the browser with [alasql](https://github.com/AlaSQL/alasql), no server needed

### Running

Just open `index.html` in a browser (an internet connection is needed: fonts and alasql are loaded from a CDN).
